## ⚡ Por Que Estão Otimizadas para Claude & GPT?

1. **Alta Densidade de Informação (Token Efficiency)**: Removidos todos os metadados de migração desnecessários, comentários redundantes e narrativas longas. Cada linha fornece regras concretas, matrizes de decisão ou snippets de código funcionais.
2. **Sem Erros de Codificação (Clean UTF-8)**: Texto 100% limpo em UTF-8, sem caracteres corrompidos.
3. **Formatadas para Ingestão de Agentes**: Cada skill possui cabeçalho YAML com `name`, `description`, `triggers` e `stack`, facilitando a indexação semântica e a recuperação contextual pelo Claude e ChatGPT.
4. **Restrições Negativas Explícitas (Negative Constraints)**: Incluem tabelas do que **NUNCA** fazer (anti-padrões), impedindo que a IA gere código genérico por inércia.
