# References — WebAssembly

> Curadoria dos melhores sites/referências (2026) para desenvolvimento WebAssembly (Wasm) no browser e em runtimes. Use como fonte de padrões e inspiração.

## Docs canônicas
- [WebAssembly.org](https://webassembly.org/) — site oficial da especificação e roadmap.
- [Wasm Core Specification](https://webassembly.github.io/spec/core/) — especificação formal da máquina virtual Wasm.
- [MDN WebAssembly](https://developer.mozilla.org/en-US/docs/WebAssembly) — API do browser e conceitos fundamentais.
- [Rust + Wasm Book](https://rustwasm.github.io/docs/book/) — guia canônico de compilação Rust para Wasm.
- [Emscripten Docs](https://emscripten.org/) — toolchain oficial de compilação C/C++ para WebAssembly.

## Referências e inspiração
- [AssemblyScript](https://github.com/AssemblyScript/assemblyscript) — TypeScript-like para Wasm (repo oficial).
- [Wasmtime](https://wasmtime.dev/) — runtime Wasm standalone da Bytecode Alliance.
- [web.dev](https://web.dev/) — artigos oficiais sobre Wasm e performance no browser.

## Comunidade / galerias / exemplos
- [WebAssembly GitHub](https://github.com/WebAssembly) — organização da especificação, toolchains e exemplos.
- [Wasm Weekly](https://wasmweekly.com/) — newsletter com novidades e exemplos da comunidade.
