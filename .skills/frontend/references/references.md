# References — Frontend

> Curadoria dos melhores sites/referências (2026) para desenvolvimento frontend (Next.js + Tailwind, design systems). Use como fonte de padrões e inspiração.

## Docs canônicas
- [MDN Web Docs](https://developer.mozilla.org/) — referência definitiva de HTML, CSS e APIs de browser.
- [web.dev](https://web.dev/) — guias oficiais do Google sobre Web moderno, performance e acessibilidade.
- [Next.js Docs](https://nextjs.org/docs) — documentação oficial do framework usado no projeto.
- [React Docs](https://react.dev/) — documentação canônica de React (components, hooks, patterns).
- [Tailwind CSS Docs](https://tailwindcss.com/docs) — tokens, utilities e configuração do design system.

## Referências e inspiração
- [Smashing Magazine](https://www.smashingmagazine.com/) — artigos profundos sobre CSS, layout e UI.
- [CSS-Tricks](https://css-tricks.com/) — técnicas, snippets e discussões práticas de CSS moderno.
- [Can I Use](https://caniuse.com/) — tabelas de compatibilidade de features de browser.
- [Storybook](https://storybook.js.org/) — padrões de documentação e desenvolvimento de componentes isolados.
- [Awwwards](https://www.awwwards.com/) — curadoria de sites premiados com design e craft de ponta.

## Comunidade / galerias / exemplos
- [Dribbble](https://dribbble.com/) — galeria de UI/UX para referência visual de componentes e páginas.
- [Frontend Mentor](https://www.frontendmentor.io/) — desafios reais de layout para praticar implementação.
- [CodePen](https://codepen.io/) — exemplos executáveis de CSS, HTML e JS.
