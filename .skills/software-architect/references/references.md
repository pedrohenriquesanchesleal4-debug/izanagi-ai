# References — Software Architect
> Curadoria dos melhores sites/referências (2026) para arquitetura de software.

## Docs canônicas
- [Martin Fowler — Architecture](https://martinfowler.com/architecture/) — artigos e opiniões de referência sobre arquitetura de software.
- [microservices.io](https://microservices.io) — catálogo de padrões de arquitetura de microserviços.
- [The Twelve-Factor App](https://12factor.net) — princípios canônicos de aplicações orientadas a serviços.

## Referências e inspiração
- [C4 Model](https://c4model.com) — modelo de diagramação arquitetural (níveis de abordagem por audiência).
- [Clean Architecture — Uncle Bob](https://blog.cleancoder.com/uncle-bob/2012/08/13/the-clean-architecture.html) — base da arquitetura em camadas independente de framework.
- [Architecture Decision Records](https://adr.github.io) — padrão para documentar decisões de arquitetura.

## Comunidade / tutorial / exemplos
- [Awesome Software Architecture](https://github.com/mehdihadeli/awesome-software-architecture) — coleção curada de padrões, princípios e artigos de arquitetura.
- [InfoQ Architecture](https://www.infoq.com/architecture-design/) — conteúdo da comunidade, talks e análises de arquitetura.
