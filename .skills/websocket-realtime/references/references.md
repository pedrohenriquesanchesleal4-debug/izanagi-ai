# References — WebSocket & Real-time

> Curadoria dos melhores sites/referências (2026) para comunicação em tempo real (WebSocket, SSE, WebRTC, Socket.IO). Use como fonte de padrões e inspiração.

## Docs canônicas
- [MDN WebSocket API](https://developer.mozilla.org/en-US/docs/Web/API/WebSocket) — referência da API WebSocket no browser.
- [MDN Server-Sent Events](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events) — streaming unidirecional com SSE.
- [RFC 6455](https://www.rfc-editor.org/rfc/rfc6455) — especificação oficial do protocolo WebSocket.
- [WebRTC](https://webrtc.org/) — site oficial de comunicação P2P em tempo real.
- [Socket.IO Docs](https://socket.io/docs/) — biblioteca de realtime com fallback automático e reconnection.

## Referências e inspiração
- [MDN WebRTC API](https://developer.mozilla.org/en-US/docs/Web/API/WebRTC_API) — referência de WebRTC no browser.
- [ws](https://www.npmjs.com/package/ws) — biblioteca WebSocket padrão para Node.js.
- [uWebSockets](https://github.com/uNetworking/uWebSockets) — implementação de alta performance em C++/Node.

## Comunidade / galerias / exemplos
- [Pusher](https://pusher.com/) — plataforma de realtime com exemplos e padrões de arquitetura.
- [Ably](https://ably.com/) — plataforma de pub/sub realtime com docs e whitepapers.
