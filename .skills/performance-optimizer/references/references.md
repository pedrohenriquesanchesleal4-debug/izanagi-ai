# References — Performance Optimizer

> Curadoria dos melhores sites/referências (2026) para otimização de performance em frontend, backend e engines. Use como fonte de padrões e inspiração.

## Docs canônicas
- [web.dev](https://web.dev/) — guias oficiais de performance de página, images, CSS e JavaScript.
- [V8 Blog](https://v8.dev/) — como a engine otimiza JS e tipagem (engine do Chrome/Node).
- [Chrome DevTools](https://developer.chrome.com/docs/devtools/) — profiler, memory e performance tools.
- [Lighthouse Docs](https://developer.chrome.com/docs/lighthouse/) — auditorias e métricas acionáveis.
- [Node.js Learn](https://nodejs.org/en/learn) — guias oficiais de performance e profiling no Node.

## Referências e inspiração
- [WebPageTest](https://www.webpagetest.org/) — testes reais com waterfalls e filmstrip.
- [Front-End Performance Checklist](https://github.com/thedaviddias/Front-End-Performance-Checklist) — checklist completo (repo).
- [Learn Web Vitals](https://web.dev/learn-web-vitals/) — fundamentos de Core Web Vitals.
- [Smashing Magazine](https://www.smashingmagazine.com/) — artigos práticos de otimização.

## Comunidade / galerias / exemplos
- [V8 Blog — perf cases](https://v8.dev/blog) — estudos de caso reais de otimização de engine.
- [perf-tools](https://github.com/brendangregg/perf-tools) — scripts e técnicas de profiling Linux (repo).
