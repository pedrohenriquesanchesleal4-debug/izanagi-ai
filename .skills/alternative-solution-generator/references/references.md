# References — Alternative Solution Generator

> Curadoria dos melhores sites/referências (2026) para explorar soluções alternativas e expandir o espaço de decisão em problemas de engenharia. Use como fonte de padrões e inspiração.

## Docs canônicas
- [Martin Fowler](https://martinfowler.com/) — análise de alternativas arquiteturais e tradeoffs com profundidade.
- [Refactoring Guru](https://refactoring.guru/) — catálogo de abordagens alternativas para um mesmo problema.
- [microservices.io](https://microservices.io/) — comparação entre padrões arquiteturais alternativos.
- [The Twelve-Factor App](https://12factor.net/) — conjunto de decisões alternativas com racional explícito.
- [Architecture Decision Records](https://github.com/joelparkerhenderson/architecture-decision-record) — template para registrar alternativas consideradas (repo).

## Referências e inspiração
- [AlternativeTo](https://alternativeto.net/) — alternativas a ferramentas e bibliotecas por necessidade.
- [Awesome Lists](https://github.com/sindresorhus/awesome) — curadorias de alternativas por ecossistema/linguagem.
- [Smashing Magazine](https://www.smashingmagazine.com/) — artigos comparando abordagens técnicas e de design.

## Comunidade / galerias / exemplos
- [Hacker News](https://news.ycombinator.com/) — discussões reais sobre prós/contras de abordagens.
- [Stack Overflow](https://stackoverflow.com/) — alternativas e soluções de problemas com votação da comunidade.
