# References — Mobile Dev

> Curadoria dos melhores sites/referências (2026) para desenvolvimento mobile (React Native, Expo, Flutter, iOS/Android). Use como fonte de padrões e inspiração.

## Docs canônicas
- [React Native Docs](https://reactnative.dev/docs) — documentação oficial de componentes e APIs nativas.
- [Expo Docs](https://docs.expo.dev/) — tooling e padrões de builds OTA, push e dev workflow.
- [Flutter Docs](https://docs.flutter.dev/) — documentação canônica de widgets, rendering e animações.
- [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/) — diretrizes de design de interfaces iOS/macOS.
- [Material Design 3](https://m3.material.io/) — design system oficial do Android com tokens e componentes.

## Referências e inspiração
- [Android Developers](https://developer.android.com/) — guias oficiais de Android, Compose e performance.
- [Apple Developer Documentation](https://developer.apple.com/documentation/) — APIs e frameworks nativos da Apple.
- [Mobbin](https://mobbin.com/) — biblioteca de padrões de UI mobile de apps reais para benchmark.
- [Smashing Magazine](https://www.smashingmagazine.com/) — artigos sobre design e dev mobile.

## Comunidade / galerias / exemplos
- [Dribbble](https://dribbble.com/) — galeria de UI mobile para inspiração de telas.
- [React Native Community](https://github.com/react-native-community) — libs, guides e discussões mantidos pela comunidade.
- [Flutter Showcase](https://flutter.dev/showcase) — apps reais construídos com Flutter como referência.
