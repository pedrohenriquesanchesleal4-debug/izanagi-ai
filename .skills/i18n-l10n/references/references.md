# References — i18n / L10n

> Curadoria dos melhores sites/referências (2026) para internacionalização e localização em aplicações web. Use como fonte de padrões e inspiração.

## Docs canônicas
- [W3C Internationalization](https://www.w3.org/International/) — guias oficiais da W3C sobre i18n e l10n.
- [Unicode CLDR](https://cldr.unicode.org/) — dados canônicos de localidades, formatos de data/número e pluralização.
- [ICU Project](https://icu.unicode.org/) — biblioteca de internacionalização que define padrões de formatação e mensagens.
- [MDN Intl](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl) — API nativa de internacionalização do JavaScript.
- [next-intl](https://github.com/amannn/next-intl) — biblioteca oficial de i18n para Next.js App Router (repo/docs).

## Referências e inspiração
- [i18next](https://www.i18next.com/) — framework de i18n mais usado no ecossistema JavaScript.
- [react-i18next](https://react.i18next.com/) — integração oficial do i18next com React.
- [FormatJS](https://formatjs.io/) — ferramentas de internacionalização baseadas em ICU para JS/React.
- [W3C: "i18n vs l10n"](https://www.w3.org/International/questions/qa-i18n) — esclarece a diferença e o escopo de cada disciplina.

## Comunidade / galerias / exemplos
- [Crowdin](https://crowdin.com/docs) — plataforma de tradução colaborativa com docs de integração.
- [Phrase](https://phrase.com/) — plataforma de gerenciamento de traduções com workflows de dev.
