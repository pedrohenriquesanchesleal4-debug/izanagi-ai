# References — GraphQL

> Curadoria dos melhores sites/referências (2026) para APIs GraphQL — schema design, servidores, clientes e ferramentas. Use como fonte de padrões e inspiração.

## Docs canônicas
- [GraphQL.org](https://graphql.org/) — site oficial: especificação, conceitos e comunidade.
- [GraphQL Specification](https://spec.graphql.org/) — especificação formal da linguagem de consulta.
- [GraphQL Learn](https://graphql.org/learn/) — introdução canônica a queries, mutations, schema e execution.
- [Apollo Docs](https://www.apollographql.com/docs/) — servidor e cliente Apollo para produção.
- [Hasura Docs](https://hasura.io/docs/) — GraphQL engine com geração automática de API sobre banco.

## Referências e inspiração
- [The Guild — GraphQL Tools](https://the-guild.dev/graphql/tools) — toolkit de schema stitching, mocks e codegen.
- [GraphQL Code Generator](https://the-guild.dev/graphql/codegen) — geração de tipos TypeScript a partir do schema.
- [graphql-js](https://github.com/graphql/graphql-js) — implementação de referência em JavaScript.

## Comunidade / galerias / exemplos
- [How to GraphQL](https://www.howtographql.com/) — tutoriais hands-on de GraphQL em várias stacks.
- [GraphQL Community](https://graphql.org/community/) — lista de libraries, ferramentas e recursos por linguagem.
