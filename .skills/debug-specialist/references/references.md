# References — Debug Specialist
> Curadoria dos melhores sites/referências (2026) para depuração sistemática: reprodução, isolamento e contexto de erro.

## Docs canônicas
- [Chrome DevTools](https://developer.chrome.com/docs/devtools/) — Ferramentas oficiais de depuração no navegador.
- [MDN — Console API](https://developer.mozilla.org/en-US/docs/Web/API/console) — Referência de logging e profiling.
- [DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/) — Automação de depuração via protocolo.
- [Firefox DevTools](https://firefox-source-docs.mozilla.org/devtools-user/) — Alternativa cross-browser de debugging.

## Checklists / práticas
- [Minimal Reproducible Example](https://stackoverflow.com/help/minimal-reproducible-example) — Padrão de reprodução mínima.
- [rr — Record & Replay](https://rr-project.org/) — Gravação de execução e depuração reversível.
- [GDB](https://www.sourceware.org/gdb/) — Depuração avançada de binários e core dumps.

## Comunidade / exemplos
- [Stack Overflow](https://stackoverflow.com/) — Diagnósticos de erros compartilhados pela comunidade.
