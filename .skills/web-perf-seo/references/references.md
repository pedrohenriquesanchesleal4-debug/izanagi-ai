# References — Web Performance & SEO

> Curadoria dos melhores sites/referências (2026) para performance (Core Web Vitals) e SEO técnico/on-page. Use como fonte de padrões e inspiração.

## Docs canônicas
- [Google Search Central](https://developers.google.com/search/docs) — documentação oficial de SEO do Google.
- [Learn Web Vitals](https://web.dev/learn-web-vitals/) — curso oficial dos Core Web Vitals.
- [Lighthouse Docs](https://developer.chrome.com/docs/lighthouse/) — auditorias de perf, acessibilidade e SEO.
- [schema.org](https://schema.org/) — vocabulário de structured data para rich results.
- [PageSpeed Insights](https://pagespeed.web.dev/) — relatórios de performance em campo e laboratório.

## Referências e inspiração
- [web.dev](https://web.dev/) — artigos oficiais sobre otimização de imagens, prefetch e rendering.
- [Search Engine Land](https://searchengineland.com/) — notícias e guias de SEO prático.
- [Ahrefs Blog](https://ahrefs.com/blog/) — guias profundos de SEO técnico e keyword research.
- [Google Search Console](https://search.google.com/search-console) — dados oficiais de indexação e experiência de página.

## Comunidade / galerias / exemplos
- [WebPageTest](https://www.webpagetest.org/) — testes reais de performance com waterfalls e filmstrip.
- [Chrome for Developers](https://developer.chrome.com/) — features, deprecations e atualizações de plataforma.
