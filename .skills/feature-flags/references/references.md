# References — Feature Flags

> Curadoria dos melhores sites/referências (2026) para feature flags, feature toggles e experimentação (A/B, canary). Use como fonte de padrões e inspiração.

## Docs canônicas
- [Feature Toggles (Martin Fowler)](https://martinfowler.com/articles/feature-toggles.html) — artigo canônico sobre tipos e padrões de flags.
- [LaunchDarkly Docs](https://docs.launchdarkly.com/) — documentação da plataforma líder de feature management.
- [Flagsmith Docs](https://docs.flagsmith.com/) — plataforma open source de feature flags e remote config.
- [Unleash Docs](https://docs.getunleash.io/) — feature flag server open source self-hosteable.
- [The Twelve-Factor App — Config](https://12factor.net/config) — separação de configuração do código, base das flags.

## Referências e inspiração
- [Flipt](https://github.com/flipt-io/flipt) — engine de feature flags open source (repo).
- [PostHog Docs](https://posthog.com/docs) — feature flags, experimentos e analytics em um só produto.
- [Harness FME](https://www.split.io/) — plataforma de feature flags com trilhos de experimentação (ex-Split.io, adquirida pela Harness).

## Comunidade / galerias / exemplos
- [Martech Series](https://martech.org/) — análises de mercado sobre plataformas e casos de uso. 
- [GitHub Topics — feature-flags](https://github.com/topics/feature-flags) — repositórios e libs da comunidade.
