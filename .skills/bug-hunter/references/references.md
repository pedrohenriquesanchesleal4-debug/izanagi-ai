# References — Bug Hunter
> Curadoria dos melhores sites/referências (2026) para caça a bugs, depuração sistemática e reprodução de falhas.

## Docs canônicas
- [MDN Web Docs](https://developer.mozilla.org/) — Referência de APIs, erros e comportamentos de runtime.
- [MDN — Console API](https://developer.mozilla.org/en-US/docs/Web/API/console) — Métodos de logging e inspeção no navegador.
- [Chrome DevTools](https://developer.chrome.com/docs/devtools/) — Ferramentas oficiais de depuração no navegador.
- [Chrome DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/) — Protocolo para automação de debugging.

## Checklists / práticas
- [Stack Overflow — Minimal Reproducible Example](https://stackoverflow.com/help/minimal-reproducible-example) — Guia de como criar reproduções mínimas eficazes.
- [Rubber Duck Debugging](https://en.wikipedia.org/wiki/Rubber_duck_debugging) — Técnica de verbalização para encontrar causas lógicas.
- [rr — Record & Replay](https://rr-project.org/) — Gravação de execução para depuração reversível em Linux.
- [GDB](https://www.sourceware.org/gdb/) — Debugger clássico de linha de comando.

## Comunidade / exemplos
- [Stack Overflow](https://stackoverflow.com/) — Base de problemas e soluções já enfrentadas pela comunidade.
- [Google Testing Blog](https://testing.googleblog.com/) — Casos reais de bugs complexos em produção.
