# References — Design Pattern Advisor

> Curadoria dos melhores sites/referências (2026) para recomendação e aplicação de design patterns de software. Use como fonte de padrões e inspiração.

## Docs canônicas
- [Refactoring Guru](https://refactoring.guru/design-patterns) — explicações claras de cada padrão com exemplos de código.
- [SourceMaking](https://sourcemaking.com/design_patterns) — catálogo de patterns com intents, motivação e exemplos.
- [Martin Fowler](https://martinfowler.com/) — patterns arquiteturais, refactoring e domain modeling.
- [microservices.io](https://microservices.io/) — catálogo de padrões para arquitetura de microservices.
- [The Twelve-Factor App](https://12factor.net/) — padrões de design para aplicações SaaS de nível produção.

## Referências e inspiração
- [java-design-patterns](https://github.com/iluwatar/java-design-patterns) — coleção de padrões GoF com exemplos reais (repo).
- [Refactoring Guru — Refactoring](https://refactoring.guru/refactoring) — catálogo de refatorações com antes/depois.
- [Thoughtworks Technology Radar](https://www.thoughtworks.com/radar) — adoção de técnicas e padrões por maturidade.

## Comunidade / galerias / exemplos
- [Martin Fowler — Bliki](https://martinfowler.com/bliki/) — essays curtos e discutidos sobre patterns emergentes.
- [Stack Overflow — Design Patterns](https://stackoverflow.com/questions/tagged/design-patterns) — discussões reais sobre quando usar cada padrão.
