# References — Quality Assurance (QA)
> Curadoria dos melhores sites/referências (2026) para auditoria de qualidade, acessibilidade, performance e responsividade.

## Docs canônicas
- [MDN Web Docs](https://developer.mozilla.org/) — Documentação de referência de HTML, CSS, JS e boas práticas web.
- [W3C WAI](https://www.w3.org/WAI/) — Diretrizes de acessibilidade e recursos de avaliação.
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/) — Especificação oficial das Diretrizes de Acessibilidade de Conteúdo Web.
- [Can I Use](https://caniuse.com/) — Compatibilidade de features entre navegadores.

## Checklists / práticas
- [Playwright Docs — Locators](https://playwright.dev/docs/locators) — Guia oficial de estratégia de seletores (`getByRole` como prioridade, `getByTestId` como último recurso).
- [WebAIM](https://webaim.org/) — Checklists e artigos práticos de acessibilidade.
- [axe](https://www.deque.com/axe/) — Motor de testes de acessibilidade automatizados.
- [Lighthouse](https://developer.chrome.com/docs/lighthouse/) — Auditoria automatizada de performance, a11y e SEO.
- [web.dev Vitals](https://web.dev/vitals/) — Métricas Core Web Vitals explicadas pelo Google.
- [W3C Markup Validator](https://validator.w3.org/) — Validação oficial de HTML.
- [Google Testing Blog](https://testing.googleblog.com/) — Práticas de testes de grandes engenharias.

## Comunidade / exemplos
- [Ministry of Testing](https://www.ministryoftesting.com/) — Maior comunidade global de QA e testes.
- [Kent C. Dodds Blog](https://kentcdodds.com/blog/) — Testes e qualidade de código na prática.
